PARA USARLO EN TU PC
----------------------------------------
1. Abrí esta carpeta
2. Hacé doble clic en:  run.bat
   (o: pip install -r requirements.txt && streamlit run app_solar.py)
3. Se abre el navegador con la herramienta

Modos:
  · Descomposición — GHI → DNI + DHI (CSV / Excel / EPW)
  · Generación de EPW — plantilla medidos + EPW base

----------------------------------------
PARA PONERLO ONLINE (internet)
----------------------------------------
1) Subí este proyecto a GitHub (GitHub Desktop)
2) Entrá a https://share.streamlit.io
3) New app → Main file: app_solar.py → Deploy
4) Compartí el link .streamlit.app
